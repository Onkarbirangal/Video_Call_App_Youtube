# 📹 Video Call App

A modern **real-time video calling web application** built using **React.js** and modern web technologies.

The project provides a browser-based interface for video communication and demonstrates the use of real-time communication technologies in a React application.

---

## 🌐 Live Demo

👉 https://video-call-app-youtube.vercel.app/

---

# ✨ Features

- 📹 Video calling
- 🎤 Audio communication
- 📷 Camera support
- 🎙️ Microphone support
- 🌐 Browser-based communication
- ⚡ Real-time communication
- 💻 Responsive user interface
- 🚀 Vercel deployment
- ⚛️ React-based frontend
